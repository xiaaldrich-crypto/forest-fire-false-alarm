## 3. 指标定义

| 名称 | 定义 |
|------|------|
| 严格分类正确 | 标注为真实\* 且系统输出疑似真实火情；或标注为\*误报 且输出疑似误报 |
| 漏报 | 标注为真实\*，但未输出疑似真实火情 |
| 误报抬真火 | 标注为\*误报，但输出疑似真实火情 |
| 真火检出率 | 真火样本中判为疑似真实火情的比例 |
| 误报过滤率 | 误报样本中判为疑似误报的比例 |

### 4.1 迭代要点

1. **N3 → 问题**：祭祀/农业/强光易被 OpenCV 火点信号抬成真火。  
2. **N4 → 处理**：高置信误报类型优先落地；抬真火降为 0，但部分真火/林缘被写成农用误报（漏报回升）。  
3. **N5/N6 → 收敛**：规则真火 / 明显火点 / 大烟伴火点 / 超大低亮烟雾等条件回抬真实烟火，同时保持误报过滤。

## 5. 局限性与风险说明

1. **样本量有限（38）**：满分代表本标注集验证通过，不代表外场全量必然 100%。  
2. **类别不均衡**：祭祀仅 2 条，外场需持续补充。  
3. **多模态依赖网络与额度**：Key 失效时降级为规则路径，指标可能下降。  
4. **视频编码**：系统已对上传 MP4 做 moov 前置（faststart），便于完整拖动浏览。
