## 一、课题背景与目标

森林火灾监控系统会产生大量烟火告警，其中夹杂强光反射、祭祀用火、农业烧荒、工厂排气、云雾等误报。若全部交人工，处置压力大；若误过滤真实火情，则安全风险不可接受。

本课题目标是搭建**简化版二次判别原型**：

1. 理解监控告警 → 复核 → 处置流程；  
2. 用 OpenCV 提取火焰/烟雾/亮度等传统特征；  
3. 结合误报规则与多模态大模型做二次判别；  
4. 形成可演示 Web 系统，并完成批量测试与总结。

**安全原则贯穿始终：宁可转人工复核，避免漏报真实火情。**

## 三、技术路线与实现

整体流水线与规划一致：

```text
报警图片/视频
    → OpenCV 特征与可视化
    → 规则初判（误报类型评分）
    → 多模态大模型复核（结构化 JSON）
    → 融合决策（最终结论 + 理由）
    → Web 展示 / 批量 Excel 导出
```

### 3.1 传统图像算法（OpenCV）

实现亮度/高亮、火焰与烟雾面积、框选可视化、视频均匀抽帧与火/烟持续性、烟柱形态分等，对应规划「传统图像算法入门」。

### 3.2 误报规则库

`config/rules.json` 固化五类误报典型表现、规则要点、是否需要人员辅助及阈值，对应「误报规则库建设」。

### 3.3 多模态二次判别

- 接口：DashScope OpenAI 兼容模式  
- 模型：`qwen-vl-max`  
- 内容：告警图/视频关键帧 + OpenCV/规则摘要 + few-shot 示例  
- 输出：是否真火、误报类型、置信度、决策、理由（JSON）

### 3.4 原型系统（FastAPI + 前端）

ForestGuard 判别平台主要能力：

- 图片/视频上传与拖拽预览  
- 判别过程面板（特征→规则→多模态→融合）  
- 结论、特征仪表、决策链路、多层可视化  
- 完整视频回放（含 MP4 faststart，便于拖动进度条）  
- 任务历史（本地）与样本库批量导出 Excel  

启动：

```bash
cd ~/Desktop/forest-fire-false-alarm
source .venv/bin/activate
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

## 四、测试结果与收获

### 4.1 最终测试结果

定稿文件：`docs/验收材料/最终批量测试_20260724_152606.xlsx`

| 指标 | 结果 |
|------|------|
| 严格准确率 | **100%（38/38）** |
| 漏报 | **0** |
| 误报抬真火 | **0** |
| 图片 / 视频 | 均为 100% |

详细分析见 `docs/02_测试报告.md`。

### 4.2 主要收获

1. **业务上**：理解了「过滤误报」与「不能漏报」之间的张力，以及人员信息只能辅助的原因。  
2. **技术上**：完成传统 CV + 规则 + 多模态 + 融合的完整链路，而不是单点调模型。  
3. **工程上**：用 FastAPI 做出可演示平台，批量评估可复现，便于验收。  
4. **方法上**：错例驱动迭代（先压抬真火，再补漏报）比一味加严或放宽更有效。

### 4.3 不足与展望

1. 标注集规模有限，外场泛化需继续扩样；  
2. 云雾与涉林真烟、农用火与失控火情边界仍依赖融合启发式；  
3. 可探索轻量时序模型/检测模型与现有规则-多模态框架融合；  
4. 人工复核工单、权限与监控平台对接可在后续工程化中完善。
