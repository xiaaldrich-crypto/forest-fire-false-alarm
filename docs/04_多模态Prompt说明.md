# 多模态二次判别 Prompt 说明

> 对应规划「阶段四：多模态二次判别」产出。  
> 源码：`app/multimodal.py`；示例图：`config/few_shot.json`。

## 1. 调用方式

- API：阿里云百炼 OpenAI 兼容接口（`LLM_API_BASE`）
- 模型：`qwen-vl-max`（以 `.env` 为准）
- 输入：告警图片或视频关键帧 + OpenCV/规则摘要 + few-shot 示例图
- 输出：结构化 JSON（是否真火、误报类型、置信度、决策、理由）

## 2. Prompt 模板（定稿摘要）

```text
你是森林火灾监控二次判别专家。请给出明确结论（尽量只要真火/误报两档）。

【目标】在防漏报前提下提高准确率：类型明确的误报必须判「疑似误报」。

【疑似真实火情】
- 林区/林缘烟柱、烟团、涉林烟雾（大面积灰白在林区也不要轻易说云雾）
- 林地燃烧、火情告警

【疑似误报】（高置信时必须判误报，不要抬成真火）
- 强光误报：反光/太阳眩光，金属高亮，无持续烟柱
- 工厂排气：烟囱厂房白烟蒸汽
- 农业用火：农田、田埂、荒地烧荒；红褐色过火迹在耕地/荒地也算农用火
- 祭祀用火：墓地、很小火点、短时烟
- 云雾：均匀铺开、无烟源、无火；密林升起烟雾则改判真实烟情

【禁止】
- 把强光眩光、墓地小火、农田烧荒抬成「疑似真实火情」
- 把涉林真实烟雾判成云雾误报
- 习惯性「建议人工复核」

输出 JSON：
is_real_fire / false_alarm_type / confidence / decision / reason
```

## 3. Few-shot

`config/few_shot.json` 含真实烟情、真实火情、强光、工厂、农业难例、祭祀等标注示例，用于对齐模型口径。

## 4. 与融合层关系

多模态输出后由 `app/pipeline.py` 融合：  
高置信明确误报类型优先落地；关键漏报条件（规则真火、大烟伴火点、超大低亮烟雾等）回抬真实烟火。
